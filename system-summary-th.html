2. ฟีเจอร์ทั้งหมด

📝 รับแจ้งซ่อม
เลือกบ้านจากทะเบียน (เติมโซน/เจ้าของ/เบอร์อัตโนมัติ), เลือกประเภทงาน, ความเร่งด่วน, แนบรูป, ระบุผู้รับแจ้ง และวันที่แจ้ง
👷 มอบหมายงาน
เลือกช่างผู้รับผิดชอบ ระบบแสดงจำนวนงานค้างของช่างแต่ละคนเพื่อช่วยกระจายงาน
🚦 ความเร่งด่วน + SLA
ด่วนมาก / ด่วน / ปกติ พร้อมเตือน “เกิน SLA” อัตโนมัติเมื่อค้างเกินเวลาเป้าหมาย
🕒 ติดตามสถานะ
6 สถานะ พร้อมไทม์ไลน์ประวัติการดำเนินงานทุกครั้งที่อัปเดต
📅 วันที่ 4 จุด
แจ้งซ่อม / เข้าประเมินหน้างาน / เข้าซ่อม / งานเสร็จ — เติมอัตโนมัติตามสถานะ และคำนวณเวลารวม
💰 ค่าใช้จ่าย
ประเมินค่าใช้จ่าย + ค่าใช้จ่ายจริง แสดงส่วนต่าง และสรุปยอดในแดชบอร์ด
🏘️ ทะเบียนบ้าน 124 หลัง
รายชื่อบ้านพร้อมโซน/เจ้าของ/เบอร์, ค้นหา/กรอง, ประวัติซ่อมรายหลัง, นำเข้ารายชื่อแบบวางทีเดียว
💬 แจ้งเข้า LINE
ปุ่มส่งข้อความสรุปงานเข้าไลน์ + (เมื่อต่อคลาวด์) ส่งอัตโนมัติเมื่อมอบหมายช่าง
📊 แดชบอร์ด
สรุปงานตามสถานะ/ความเร่งด่วน, ภาระงานช่าง, เกิน SLA, เวลาซ่อมเฉลี่ย, ยอดค่าใช้จ่าย
📋 บอร์ดสถานะ (Kanban)
มุมมองการ์ดแยกตามสถานะ เห็นงานไหลจากซ้ายไปขวา
🔎 ค้นหา/กรองงาน
ค้นด้วยรหัสงาน/ลูกค้า/หัวข้อ/สถานที่ และกรองตามสถานะ/ความเร่งด่วน/ช่าง
👥 จัดการทีมงาน
เพิ่ม/แก้/ลบ ช่างและพนักงานรับแจ้ง ดูภาระงานและงานที่รับแจ้งของแต่ละคน
💾 ข้อมูล & สำรอง
บันทึก/โหลดไฟล์ JSON สำหรับสำรองข้อมูล และซิงก์ขึ้นคลาวด์เมื่อเชื่อมต่อ

6. สถาปัตยกรรมตอนใช้งานจริง

💻 เว็บแอป (ทุกเครื่อง/มือถือ)⇄ 📜 Google Apps Script⇄ 📊 Google Sheet (ฐานข้อมูลกลาง)
📜 Apps Script→ 💬 LINE Messaging API→ 📱 กลุ่มช่าง / ช่างรายคน

ทุกคนที่เปิดเว็บแอปด้วยค่าเชื่อมต่อเดียวกันจะเห็นข้อมูลชุดเดียวกัน และรีเฟรชอัตโนมัติทุก ~12 วินาที

7. ✅ เช็คลิสต์ก่อน Go-Live

  • สร้าง Google Sheet และวางโค้ด Code.gs ใน Apps Script
  • ตั้งรหัสลับ (API_KEY) และ Deploy เป็น Web app (Execute as: Me / Access: Anyone)
  • ใส่ URL + รหัสลับในเว็บแอป (ตัวแปร CLOUD) และเห็น “☁️ ซิงก์แล้ว”
  • สร้าง LINE Official Account + Messaging API และใส่ Channel access token ใน Code.gs
  • เชิญบอทเข้ากลุ่มช่าง และตั้งค่าปลายทาง (LINE_TO) แล้ว Deploy เวอร์ชันใหม่
  • ทดสอบ: แจ้งงาน 1 ใบ + มอบหมายช่าง → ข้อความเด้งเข้ากลุ่ม LINE
  • นำเข้ารายชื่อบ้าน 124 หลังจริง (เลขที่/โซน/เจ้าของ/เบอร์)
  • ใส่ความชำนาญ/เบอร์โทรของช่างแต่ละคน (ถ้าต้องการ)
  • เปิดเว็บแอปในอีกเครื่อง/มือถือ ยืนยันว่าเห็นข้อมูลตรงกัน
  • แจ้งทีมงานเรื่องวิธีเข้าใช้ และตกลงว่าใครดูแลงานส่วนไหน

8. ข้อควรระวัง

⛔ ไฟล์ HTML มีรหัสลับอยู่ข้างใน — แชร์เฉพาะภายในทีมเท่านั้น อย่าเผยแพร่สู่สาธารณะ
⚠️ แก้โค้ด Code.gs แล้วต้อง Deploy เวอร์ชันใหม่ทุกครั้ง (Manage deployments → New version) ถึงจะมีผล
⚠️ การแก้พร้อมกัน: ใช้หลัก “บันทึกล่าสุดทับของเดิม” — ถ้าสองคนแก้งานใบเดียวกันในวินาทีเดียวกันอาจทับกันได้ ทีมเล็กมักไม่ชนกัน แต่ควรตกลงหน้าที่กันไว้
💡 สำรองข้อมูล: Google Sheet เก็บอัตโนมัติ + มีปุ่มบันทึก JSON ในเว็บแอปให้ดาวน์โหลดสำรองเป็นระยะ

9. ต่อยอดได้ในอนาคต

  • ส่ง LINE แยกรายช่าง (ไม่ใช่เข้ากลุ่มรวม) โดยเก็บ LINE userId ของช่างแต่ละคน
  • ให้ลูกค้าให้คะแนนความพึงพอใจหลังปิดงาน
  • รายงานสรุปรายเดือน + ส่งออก Excel/PDF สำหรับผู้บริหาร
  • บันทึกอะไหล่/วัสดุที่ใช้ต่องาน และงานซ่อมบำรุงเชิงป้องกันตามรอบ (PM)
  • ระบบสิทธิ์ผู้ใช้ (CS / ช่าง / หัวหน้า) และการอนุมัติค่าใช้จ่ายเมื่อเกินวงเงิน
  • แจ้งเตือนงานค้าง/เกิน SLA อัตโนมัติเข้า LINE
