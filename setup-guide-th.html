ภาพรวมระบบ

เว็บแอป (ไฟล์ HTML) จะคุยกับ Google Apps Script ซึ่งเก็บข้อมูลทั้งหมดไว้ใน Google Sheet กลาง ทุกคนที่เปิดเว็บแอปด้วย URL เดียวกันจะเห็นข้อมูลชุดเดียวกัน และเมื่อมอบหมายงาน ระบบจะยิงข้อความเข้า LINE ให้ช่างอัตโนมัติ

เวลาโดยประมาณ 30–45 นาที · ทำครั้งเดียว · ไม่มีค่าใช้จ่าย (ใช้บัญชี Google และ LINE ฟรีได้)

1 ตั้งฐานข้อมูลด้วย Google Sheet + Apps Script

  1. ไปที่ sheets.new เพื่อสร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น ฐานข้อมูลแจ้งซ่อม
  2. บนแถบเมนู เลือก ส่วนขยาย (Extensions) → Apps Script
  3. ลบโค้ดตัวอย่างที่ขึ้นมา (function myFunction(){}) ให้หมด แล้ววางเนื้อหาทั้งหมดจากไฟล์ Code.gs ลงไป
  4. แก้บรรทัดตั้งค่าด้านบนสุด ตอนนี้ตั้งแค่รหัสลับก่อน (LINE ค่อยทำในขั้นที่ 3): 
    const API_KEY = 'CHANGE_ME_ตั้งรหัสลับเอง';   // ← ตั้งรหัสลับของคุณเอง เช่น 'baan124-secret'
  5. กดไอคอน 💾 บันทึก (Save project)
💡 รหัสลับ (API_KEY) คือกันไม่ให้คนนอกยิงข้อมูลเข้าระบบ ตั้งเป็นข้อความอะไรก็ได้ที่เดายาก แล้วจำไว้ใช้ในขั้นที่ 2

2 เผยแพร่เป็นเว็บแอป (Deploy) และเชื่อมกับหน้าเว็บ

  1. ใน Apps Script กดปุ่ม Deploy (มุมขวาบน) → New deployment
  2. กดไอคอนเฟือง ⚙️ ข้าง "Select type" → เลือก Web app
  3. ตั้งค่า:
    ช่องเลือก
    Descriptionเว้นว่าง หรือใส่ว่า repair v1
    Execute asMe (บัญชีคุณ)
    Who has accessAnyone
  4. กด Deploy → ครั้งแรกจะขึ้นให้ Authorize access ให้กดอนุญาต (เลือกบัญชี → Advanced → Go to project → Allow)
  5. คัดลอก Web app URL ที่ได้ (ลงท้ายด้วย /exec)
  6. เปิดไฟล์ home-repair-system.html ด้วยโปรแกรมแก้ข้อความ (เช่น Notepad / TextEdit) ค้นหาบรรทัด: 
    const CLOUD = { url:"", key:"" };
    แล้วใส่ URL กับรหัสลับให้ตรงกับที่ตั้งไว้: 
    const CLOUD = {
  url:"https://script.google.com/macros/s/xxxxx/exec",
  key:"baan124-secret"
};
  7. บันทึกไฟล์ แล้วเปิดในเบราว์เซอร์ — มุมขวาบนต้องขึ้น ☁️ ซิงก์แล้ว ถือว่าเชื่อมต่อสำเร็จ 🎉
⚠️ ทุกครั้งที่ แก้โค้ดใน Code.gs ต้องไป Deploy → Manage deployments → ✏️ (แก้ไข) → Version: New version → Deploy เพื่อให้โค้ดใหม่มีผล (URL เดิมไม่เปลี่ยน)

3 ตั้งการแจ้งเตือนเข้า LINE อัตโนมัติ

3.1 สร้าง LINE Official Account + ช่อง Messaging API

  1. ไปที่ LINE Developers Console เข้าสู่ระบบด้วยบัญชี LINE
  2. สร้าง Provider ใหม่ (เช่น ชื่อหมู่บ้าน) → สร้าง Channel ประเภท Messaging API
  3. เข้าไปที่แท็บ Messaging API → เลื่อนลงหา Channel access token (long-lived) → กด Issue แล้วคัดลอกไว้
  4. นำ token ไปวางใน Code.gs: 
    const LINE_TOKEN = 'วาง token ที่คัดลอกมาตรงนี้';

3.2 หา "ปลายทาง" ที่จะส่งข้อความ (กลุ่มช่าง)

วิธีที่ง่ายที่สุดคือส่งเข้า กลุ่ม LINE ของทีมช่าง ทำดังนี้:

  1. ในแท็บ Messaging API ของ LINE ให้ปิด Auto-reply และเปิด Allow bot to join group chats
  2. สแกน QR เพิ่มบอทเป็นเพื่อน แล้ว เชิญบอทเข้ากลุ่มช่าง
  3. ตั้ง Webhook URL = URL เว็บแอปเดียวกัน (ลงท้าย /exec) และเปิด Use webhook
  4. พิมพ์อะไรก็ได้ในกลุ่ม 1 ข้อความ → ระบบจะบันทึก groupId ไว้ในชีต STATE ช่อง A2
  5. คัดลอก groupId นั้นไปใส่ใน Code.gs: 
    const LINE_TO = 'วาง groupId ที่ได้จากช่อง A2';
  6. กด Deploy ใหม่ (Manage deployments → New version) ตามที่เตือนไว้ข้างบน
💡 อยากส่งหาช่างเป็นรายคนแทนกลุ่ม? ทำได้ภายหลังโดยเก็บ userId ของช่างแต่ละคน (ให้ช่างทักบอท แล้วดู userId ในช่อง A2) — บอกผมได้ถ้าต้องการ เดี๋ยวเพิ่มช่องกรอก LINE ให้ในหน้าจัดการช่าง

4 ทดสอบและเริ่มใช้งาน

  1. เปิดเว็บแอป → เห็น ☁️ ซิงก์แล้ว
  2. ไปเมนู ทะเบียนบ้าน → กด นำเข้ารายชื่อ (วาง) วางข้อมูลบ้าน 124 หลังจริง (รูปแบบ: เลขที่, โซน, เจ้าของ, เบอร์)
  3. ลอง แจ้งซ่อมใหม่ แล้วมอบหมายช่าง → ข้อความควรเด้งเข้ากลุ่ม LINE อัตโนมัติ
  4. เปิดเว็บแอปด้วย URL/ไฟล์เดียวกันในอีกเครื่อง/มือถือ → ต้องเห็นงานเดียวกัน (รีเฟรชอัตโนมัติทุก ~12 วินาที)

5 การแชร์ให้ทีม & ข้อควรระวัง

วิธีให้ทีมเข้าถึง

  • ง่ายสุด: ส่งไฟล์ home-repair-system.html (ที่ใส่ค่า CLOUD แล้ว) ให้ทุกคนเก็บไว้เปิดในเบราว์เซอร์/มือถือ — ทุกไฟล์ที่มีค่า CLOUD เดียวกันจะเห็นข้อมูลชุดเดียวกัน
  • เปิดผ่านลิงก์: อัปโหลดไฟล์ขึ้น Netlify Drop (ลากไฟล์วาง ได้ลิงก์ทันที ฟรี) หรือ GitHub Pages แล้วส่งลิงก์ให้ทีม
⛔ อย่าเผยแพร่ไฟล์ที่มีรหัสลับสู่สาธารณะ เพราะไฟล์ HTML มี API_KEY อยู่ข้างใน ให้แชร์เฉพาะภายในทีมเท่านั้น (ลิงก์ Netlify แบบไม่เปิดเผย/ส่งไฟล์ตรง)
⚠️ การแก้ไขพร้อมกัน: ระบบใช้หลัก "บันทึกล่าสุดทับของเดิม" ถ้าสองคนแก้ งานใบเดียวกันในวินาทีเดียวกัน อาจทับกันได้ ในทางปฏิบัติทีมเล็กมักไม่ชนกัน แต่ควรตกลงกันว่าใครดูแลใบไหน หากต้องการกันชนแบบเข้มงวด บอกผมได้
💡 สำรองข้อมูล: Google Sheet เก็บให้อัตโนมัติอยู่แล้ว และในเว็บแอปยังมีปุ่ม บันทึกข้อมูล (JSON) ให้ดาวน์โหลดสำรองเป็นระยะได้
สรุปลำดับการติดตั้ง

Google Sheet → วาง Code.gs → ตั้ง API_KEY → Deploy เป็น Web app → คัดลอก URL ไปใส่ในเว็บแอป (CLOUD) → เชื่อม LINE (token + groupId) → นำเข้ารายชื่อบ้าน → เริ่มใช้งาน
